The problem scenario, task names and input/output schema requirements come from the [Deloitte Australia Technology Job Simulation on Forage](https://www.theforage.com/simulations/deloitte-au/technology-fz0w).

This repository is a participant's learning project. It is not an official Deloitte application or evidence of employment with Deloitte.

## Code

The conversion solution was adapted from the exercise starter and refined with UTF-8 fixture loading, exact timestamp arithmetic, timezone handling and a separate test suite. It should not be presented as an unrelated application developed from scratch.

## Data and documents

- `data/*.json` contains independently authored fictional examples in the exercise's schemas.
- `docs/development-proposal.md` contains the authored proposal in a portfolio format.
- `docs/development-proposal.pdf` is generated from that Markdown with ReportLab using standard PDF fonts.
- The original supplied template, artwork, fixtures and submitted branded PDF remain outside the public file set in the ignored local `private_reference/` directory.
